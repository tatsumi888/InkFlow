# 要求内容

## 概要

ビルド時刻とソースバージョンを、アプリ（GUI・CLI）から確認できるようにする。

## 背景

配布物（onedir/onefile）は同じ `inkflow.__version__`（例: `1.0.0`）のまま複数回ビルドされうる。開発中に何度もビルドし直したとき、「いま動いているこの実行ファいるはどのビルドか」「ソースのどの時点のコードが入っているか」を確認する手段がない。バージョン番号だけでは、同じ `1.0.0` のまま行った複数回のビルドを区別できない。

## 実装対象の機能

### 1. ソースバージョンの表示

- `__version__` に加えて、**そのコードがどのgitコミットに基づくか**（短縮コミットハッシュ）と、**作業ツリーに未コミットの変更があったか**を表示する。
- パッケージ版（PyInstallerで固めた実行ファイル）では、ビルド時点のコミット・作業ツリー状態を**ビルド時に埋め込む**（実行時に`.git`は同梱されないため）。
- ソースから直接実行した場合は、その場でgitに問い合わせて**現在**のコミット・作業ツリー状態を表示する。
- gitが使えない・`.git`が無い環境でも例外にせず、取得できなかった旨を表示する。

### 2. ビルド時刻の表示

- パッケージ版では、ビルドを実行した日時（UTC）を表示する。
- ソース実行時は「ソース実行（パッケージ版ではない）」等、ビルドという概念が無いことが分かる表示にする。

### 3. 表示箇所

- **GUI**: ヘルプメニューに「バージョン情報…」を追加し、ダイアログで表示する。
- **CLI**: `--version` の出力に含める。`selftest` の見出し行にも反映する。

## 受け入れ条件

- [ ] ソースから実行すると、現在のgitコミット（短縮ハッシュ）が表示される。
- [ ] 作業ツリーに未コミットの変更がある状態でソース実行すると、その旨が表示される。
- [ ] git が使えない環境でも、例外を出さずに「不明」等の表示に留める。
- [ ] パッケージ版をビルドすると、ビルド時点のコミット・ビルド日時が実行時に表示される（ビルド後に元のソースが変わっても、パッケージ版の表示は変わらない）。
- [ ] パッケージ版をビルドした直後にソースから実行しても、パッケージ版のビルド情報を誤って表示しない（生成物ファイルが残っていても、フリーズ判定は `sys.frozen` で行う）。
- [ ] GUIのヘルプメニューから「バージョン情報…」でダイアログ表示できる。
- [ ] `inkflow.cli --version` にバージョン・コミット・ビルド情報が含まれる。
- [ ] ビルド情報の生成に失敗しても（git不在など）、ビルド自体は失敗しない。

## スコープ外

- ビルド時刻・コミット情報をEPUBの出力物やプロジェクトファイルに埋め込むこと。
- 自動更新チェック（最新版かどうかの確認）。
