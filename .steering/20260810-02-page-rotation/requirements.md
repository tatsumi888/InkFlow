# 要求内容

## 概要

出力コマを90°回転させる設定を**ページ単位**で追加する。上下2分割・上中下3分割のように横長のコマになるレイアウトでは、回転して端末を横向きに持つほうが文字が大きく表示され、読みやすくなるため。

## 背景

出力コマは縦横比を保ったまま端末解像度（既定 1236×1648・縦長）に収められる。このため**横長のコマは画面の上下が大きく余り、文字が小さくなる**。

B5（515.9×728.5pt）を 1236×1648 へ出力したときの試算:

| レイアウト | コマの縦横比 | 回転なしの画面使用率 | 回転時の画面使用率 | 文字サイズ比 |
|---|---|---|---|---|
| `half_v`（上下2分割） | 1.42（横長） | 53% | 94% | **1.33倍** |
| `third_v`（上中下3分割） | 2.13（横長） | 35% | 94% | **1.33倍** |
| `quad_2col`（二段組4分割） | 0.71（縦長） | 94% | 71% | 0.75倍（悪化） |

横長のコマでは回転が明確に有利、縦長のコマでは明確に不利。**どちらが良いかは誌面とレイアウトに依存する**ため、自動判定ではなくページごとの人手選択とする。これは既存の分割レイアウト選択と同じ方針。

## 実装対象の機能

### 1. ページ単位の回転設定

- 各原稿ページに「縦横入替」の設定を持たせる。**なし／右90°／左90°**の3択。
- 右90°・左90°の両方を用意するのは、端末をどちら向きに持つかが人によって違うため。
- 回転はそのページから生成される**すべての出力ページに適用する**（俯瞰ページも含む）。1ページ分を読む間に端末を持ち替えずに済ませるため。
- 既定は「なし」。既存のプロジェクトを読み込んだときも「なし」になる。

### 2. 回転を織り込んだ解像度計算

- 回転する場合、コマの幅は端末の**高さ**に、高さは**幅**に対応する。必要レンダリング解像度の算出でこれを反映し、回転後に拡大による滲みが起きないようにする。

### 3. GUI での選択と確認

- 右パネルに「縦横入替」の3択を置く。キー `R` で なし → 右90° → 左90° → なし と巡回できる。
- プレビュー上に、回転が設定されていることと向きが分かる表示を出す。
- 記事ツリーのページ行にも回転の有無を表示する。
- 「前ページと同じ」「この記事の全ページに適用」「全ページに適用」で回転設定も一緒に複製される。

### 4. CLI とプロジェクトファイル

- CLI に `--rotate {none,cw,ccw}` を追加し、既定値として全ページに適用できる。
- プロジェクトファイルに回転設定を保存・復元する。

## 受け入れ条件

### ページ単位の回転設定

- [ ] `PageSpec` に回転を持たせ、0°／90°（右）／270°（左）以外の値は既定（0°）に落ちる。
- [ ] 回転を設定しても、そのページの出力ページ**枚数は変わらない**。
- [ ] 回転したページの出力画像も、端末解像度ちょうどの寸法になっている。
- [ ] 右90°と左90°で、出力画像が互いに異なる（180°違いになっている）。
- [ ] 俯瞰ページにも回転が適用される。

### 解像度計算

- [ ] 回転を指定すると、必要DPIの算出で端末の幅と高さが入れ替わる。
- [ ] 横長のコマ（`half_v`）を回転して出力すると、回転なしより本文が大きく描かれる。

### GUI

- [ ] 右パネルで回転を選ぶと、プレビューの表示と記事ツリーの行が即座に更新される。
- [ ] `R` キーで なし → 右90° → 左90° → なし と巡回する。
- [ ] レイアウトを変えても回転設定は保持される。
- [ ] 俯瞰の有無を切り替えても回転設定は保持される。
- [ ] 「前ページと同じ」で回転設定も複製される。
- [ ] 「この記事の全ページに適用」「全ページに適用」で回転設定も広がる。
- [ ] プロジェクトを保存して開き直すと回転設定が復元される。

### CLI

- [ ] `--rotate cw` / `--rotate ccw` で全ページに回転が適用される。
- [ ] プロジェクトファイル入力に対しても `--rotate` で上書きできる。

## 成功指標

- `half_v`（上下2分割）を回転して出力したとき、画面使用率が53%から94%に上がる（＝文字が1.33倍になる）。
- 既存の出力（回転なし）に一切影響しない。既存プロジェクトの再生成結果が変わらないこと。

## スコープ外

- 回転の自動判定（コマの縦横比から機械的に決める機能）。誌面によって最適解が違うため人手選択とする。
- 180°回転。「縦横入替」という目的に対して意味がない。
- 端末側の向き指定（EPUB の `rendition:orientation`）の変更。画像そのものを回転させるので不要。
